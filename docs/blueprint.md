# **App Name**: CineSearch

## Core Features:

- Movie Listing: Display a scrollable list of movies, fetched from the API. Each movie shows its image, title, and basic info.
- Movie Search: Enable users to search for movies using a search bar that filters results dynamically.
- Movie Details: Show details such as cast, crew, and related movies for any movie in a dedicated page. When viewing the movie page, the app will trigger an API call to load all of the movie's related data
- TV Show Listing: Display a scrollable list of TV shows, fetched from the API, similar to movies.
- TV Show Search: Enable users to search for TV shows using a search bar that filters results dynamically.
- TV Show Details: Provide a detailed page for each TV show, including a description and related shows. When viewing the tv show page, the app will trigger an API call to load all of the tv show's related data.
- AI-Powered Recommendations: Based on the movie's or TV show's description, an AI tool provides users with content recommendations.
- Language Selection: Add a language selection button in the navbar to support dual languages.
- Theme Toggle: Implement a light/dark mode toggle in the navbar.
- User Profiles with Likes: Create user profiles where users can like movies and TV shows, adding them to their profile.

## Style Guidelines:

- Primary color: Dark blue (#24305E) to convey a sense of depth, immersion, and cinematic feel.
- Background color: Very dark grey (#12182B) to create an immersive, theater-like atmosphere, that puts focus on the visual content.
- Accent color: Orange (#E07A5F) to draw attention to key interactive elements, while also complementing the primary dark blue hue.
- Body and headline font: 'Inter', a sans-serif font for a clean, modern, and easily readable user experience.
- Use minimalist, white colored icons for navigation and controls, ensuring clarity and ease of use.
- Employ a grid-based layout with generous spacing to showcase movie and TV show posters effectively. The goal is to allow easy browsing and prevent visual clutter.
- Add subtle fade-in effects and transitions when loading content or navigating between pages to enhance the user experience.
